# Sistema de Administración Comunitaria Los Robles

Proyecto académico desarrollado con React + Vite para la Actividad 3.

## Funcionalidades
- Inicio y navegación por secciones.
- Avisos comunitarios.
- Servicios del portal.
- Formulario de reportes y sugerencias.
- Confirmación de envío.
- Registro local del último reporte con localStorage.
- Diseño responsive para celular y computadora.

## Ejecutar
1. Instalar Node.js.
2. `npm install`
3. `npm run dev`
4. Abrir la dirección local que muestre Vite.

## Compilar
`npm run build`

## Nota
El formulario es una demostración local. La integración con API/base de datos del backend queda como siguiente etapa del proyecto.
